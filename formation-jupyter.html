Vos analyses méritent mieux qu'un fichier Excel envoyé par email. Jupyter vous permet de combiner code, explications textuelles et graphiques animés dans un seul document partageable.

  • Maîtrise de l'environnement JupyterCréez, structurez et mettez en forme vos notebooks avec Markdown, HTML et LaTeX.
  • Rapports dynamiques et interactifsIntégrez des widgets dynamiques (ipywidgets) et des visualisations avec Matplotlib.
  • Export et partage professionnelsExportez en HTML/PDF, versionez avec Git et découvrez Jupyter Book pour la publication.

Programme Détaillé

Une journée intensive pour maîtriser le data storytelling avec Jupyter.

9h00 - 10h30 : Introduction à Jupyter Notebook

  • Les bases: Qu'est-ce que Jupyter Notebook ? Interface et navigation.
  • Configuration: Installation via Anaconda.
  • Gestion: Création, ouverture et enregistrement de notebooks. Raccourcis clavier courants.
  • Atelier: Création d'un notebook simple avec code et texte.

10h45 - 12h00 : Mise en forme et cellules

  • Markdown & HTML: Mise en forme avec Markdown, HTML et LaTeX (titres, listes, équations).
  • Le Noyau: Exécution des cellules de code et gestion du noyau (interruption, redémarrage).
  • Atelier: Formatage d'un notebook mixant texte enrichi et code Python.

13h00 - 14h15 : Visualisations et interactions

  • Interactivité: Introduction aux widgets interactifs avec ipywidgets (sliders, boutons).
  • Graphiques: Création de graphiques de base avec Matplotlib intra-notebook.
  • Atelier: Création d'un graphique interactif piloté par un widget.

14h30 - 16h00 : Partage, export et projet final

  • Livrables: Exportation des notebooks en HTML et PDF.
  • Versioning: Introduction à Git pour la gestion des versions du notebook.
  • Publication: Présentation rapide de Jupyter Book pour la création de livres numériques.
  • Projet final: Notebook complet avec texte formaté, graphique interactif et export partageable.
